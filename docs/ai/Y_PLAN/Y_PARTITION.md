## B — Anti-collision law (the load-bearing decision)

1. **Galaxies CREATE per-galaxy builder modules. Galaxies NEVER edit
   chokepoints.** The 5 shared chokepoint files
   (`KloelGraphShell.tsx`, `KloelGraphShell.helpers.ts`,
   `KloelGraph.static-nodes.ts`, `KloelGraph.routes.ts`,
   `KloelGraphNodeButton.tsx`) are serial-owned by S0/S1/S8/S9/S10 only.
2. **Every chokepoint edit MUST `task_lock_acquire` + `atomic_lock_acquire`
   first**, and locks are **verified, not trusted** — the pre-flight gate (§H)
   confirms the lock before any chokepoint write; a missing lock is fail-closed.
3. `KloelGraphTheme.tsx`, `KloelGraphPrototype.jsx` are **DO-NOT-EDIT /
   read-only** reference files. `KloelGraphOverlay.tsx` is **DO-NOT-EDIT EXCEPT
   the single written S10 a11y exception** (§ "S10 Overlay exception" below).
4. **Honest state everywhere**: where a backend is absent, errors, is loading, or
   returns zero rows, the builder emits **zero nodes**. Never a seed, never fake
   data. Builders MUST distinguish error from empty (both → `[]`, never throw up
   to the Shell).
5. **Cross-worktree**: this partition lands ONLY in
   `/Users/danielpenin/whatsapp_saas` @ `feat/kloelgraph-prototype-engine`.
   ≥6 sibling kloelgraph worktrees exist; the pre-flight gate (§H) ABORTS the
   fan-out if any sibling worktree holds a lock on a chokepoint or is executing
   Y. Locks are advisory across worktrees, so the gate is the real guard.
6. **Galaxies emit ONLY plain-branch routes** (no entity query params) **until S9
   lands.** A galaxy that needs a drilldown query (`?conversation=`, `?areaId=`,
   etc.) lists the param in its receipt and ships the plain-branch route first; a
   follow-up after S9 swaps to the query route. This eliminates the
   no-node-resolvable window (S9 also scaffolds a resolver fallback to the
   plain-branch route — see §D / S0 / S9).
