## OpenCode Execution Mode Check

`scripts/orchestration/opencode-fleet.mjs` launches `opencode run -m deepseek/deepseek-v4-pro --variant max --format default`, writes each prompt to `artifacts/opencode-fleet/<runId>/<task-id>.prompt`, captures stdout/stderr to `.out` and `.err`, writes `.exit`, tracks `pids.json`, and writes `summary.json`.

Classification:

- `INTERATIVO`: not provided by this runner; stdin is ignored for child agents.
- `OBSERVAVEL`: yes, stdout/stderr/exit are captured per task.
- `AUDITAVEL`: yes, prompt/log/exit/summary artifacts are persisted.
- `ACEITAVEL`: yes for non-PULSE discovery tasks after rule applicability audit; PULSE auditor debt tasks still inherit the PULSE-only live-interactive rule.
